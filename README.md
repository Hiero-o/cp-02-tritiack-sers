# cp-02-tritiack-sers

O projeto tem como objetivo aplicar técnicas de Machine Learning utilizando dados obtidos de APIs públicas relacionadas à geração de energia e condições meteorológicas.

Os dados da tarefa foram obtidos por meio da API pública SIGA da ANEEL (Agência Nacional de Energia Elétrica). Os dados representam empreendimentos de geração de energia no Brasil e foram utilizados para classificar as fontes em três categorias: Solar, Eólica e Hidráulica.

# Dados Utilizados:

- aneel_classificacao_orange.csv — dados dos empreendimentos de geração obtidos da ANEEL.
- meteo_regressao_orange.csv — dados meteorológicos e de radiação solar obtidos da Open-Meteo.
